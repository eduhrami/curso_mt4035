## Project Overview

This is a curriculum documentation repository for **MT4035** — a university course on data analytics applied to retail, e-commerce, and supply chain management. All content is written in Spanish. There is no source code, build system, or test suite — this is a pure markdown documentation project.

## Repository Structure

- `README.md` — Course index, learning objectives, and final project details
- `sesion-1.md` through `sesion-8.md` — One file per class session, each following the same structure
- `curso_anterior/` — Reference-only archive of the previous version of MT4035 (see "Previous course version" below)

## Session File Structure

Every session file follows this consistent template:
1. **Descripción** — Session summary and instructor assignment
2. **Objetivos de aprendizaje** — Learning objectives
3. **Estructura sugerida en clase** — Suggested in-class time breakdown
4. **Subtemas** — Detailed subtopic list with explicit non-overlap notes referencing other sessions
5. **Preparación del estudiante** — Student preparation tasks
6. **Entregable** — Team deliverable tied to the final project
7. **Lecturas** — Textbook reference (APA format) + supplements

## Course Progression

**Phase 1 — Foundations & Customer Analytics (Sessions 1–3):** KPI taxonomy, customer segmentation (RFM/CLV), demand forecasting, A/B testing

**Phase 2 — Supply Chain & Operations (Sessions 4–5):** Network design, inventory models (EOQ/ROP), fulfillment, last-mile logistics

**Phase 3 — Commercial & Emerging Tech (Sessions 6–7):** Pricing, promotions, fraud detection, IoT, AI/ML, automation, blockchain

**Capstone (Session 8):** Team presentations + individual exam

- Deliverables in each session connect directly to the team's final project (real retailer analysis). Keep this continuity when modifying content.
